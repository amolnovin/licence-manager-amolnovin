=== لایسنس منیجر آمل نوین ===
Version: 1.0.7

== تغییرات ==
- تشخیص خطای 404 سمت وب‌سرور در تست ارتباط و بررسی وضعیت rewrite/permalink.
- افزودن fallback با ?rest_route= برای تایید سالم بودن REST API حتی وقتی /wp-json 404 می‌دهد.
- افزودن بخش «بررسی ارتباط با سرور» در بالای صفحه مدیریت.
- نمایش وضعیت آنلاین/آفلاین بودن سرور amolnovin.ir.
- بررسی اعتبار گواهی SSL سرور.
- نمایش زمان پاسخ سرور و کد HTTP.
- بررسی عملکرد API لایسنس.
- نمایش جزئیات پاسخ سرور در صورت خطا.
- ذخیره نتیجه آخرین بررسی در دیتابیس.
- دکمه آزمایش ارتباط با Ajax برای بررسی فوری.

== نسخه 1.0.5 ==
- حذف نمایش و ذخیره اثر انگشت MD5 برای کلید لایسنس.
- فیلد کلید لایسنس دوباره به صورت معمولی و قابل مشاهده/ویرایش نمایش داده می‌شود.
- کلید اصلی بدون تبدیل MD5 برای فعال‌سازی و بررسی به API ارسال می‌شود.
