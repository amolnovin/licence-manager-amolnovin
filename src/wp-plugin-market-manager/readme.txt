=== سامانه فروش و لایسنس افزونه و قالب ===
Contributors: arena
Requires at least: 6.2
Requires PHP: 7.4
Stable tag: 1.2.3
License: GPLv2 or later

سامانه اختصاصی فروش، معرفی، لایسنس آنلاین، بروزرسانی و پیامک برای افزونه‌ها و قالب‌های وردپرس.

== نسخه فعلی ==
- فروش کاملاً اختصاصی و مستقل از افزونه فروشگاهی دیگر
- صفحه لیست افزونه و قالب‌ها با shortcode [wplm_store]
- دسته‌بندی افزونه و قالب‌ها
- تک‌صفحه معرفی محصول با فرم ثبت/خرید
- دریافت اطلاعات کاربر، ایمیل، موبایل و دامنه
- ایجاد حساب کاربری خودکار برای مشتریان جدید
- ارسال کاربر به درگاه پرداخت زیبال
- callback و verify پرداخت زیبال
- صفحه نتیجه خرید با shortcode [wplm_payment_result]
- حساب کاربری نمایش خریدها و لایسنس‌ها با shortcode [wplm_account]
- ایجاد خودکار لایسنس پس از پرداخت موفق
- ارسال ایمیل و پیامک لایسنس
- REST API فعال‌سازی/بررسی لایسنس و بروزرسانی

- مدیریت نسخه‌ها و آپلود فایل ZIP امن
- تولید لینک دانلود امن و زمان‌دار برای بروزرسانی
- API استاندارد بررسی بروزرسانی افزونه
- فایل client/wplm-plugin-updater.php برای نمایش آپدیت در صفحه افزونه‌های وردپرس
- اتصال پیامک IPPanel Core

- مدیریت پیشرفته لایسنس‌ها
- ایجاد دستی لایسنس
- ویرایش ایمیل، موبایل، محصول، تاریخ انقضا و تعداد دامنه مجاز
- فعال/غیرفعال/مسدود/منقضی کردن لایسنس
- تمدید سریع لایسنس
- حذف دامنه‌های فعال از هر لایسنس
- ارسال مجدد ایمیل و پیامک اطلاعات لایسنس

- دانلود آخرین نسخه محصول از حساب کاربری مشتری
- نمایش changelog آخرین نسخه در حساب کاربری
- نمایش وضعیت لایسنس، تاریخ اعتبار و دامنه‌های فعال
- دکمه کپی کلید لایسنس
- لینک دانلود امن حساب کاربری با بررسی مالکیت سفارش و لایسنس

- مدیریت کدهای تخفیف و کمپین فروش
- تخفیف درصدی یا مبلغ ثابت
- محدودیت تخفیف برای محصول یا دسته‌بندی خاص
- تاریخ شروع و پایان تخفیف
- سقف تعداد استفاده از کد تخفیف
- اعمال کد تخفیف در فرم خرید اختصاصی
- ثبت مبلغ اولیه، مبلغ تخفیف و مبلغ نهایی در سفارش‌ها
- آمار فروش و جمع تخفیف‌ها در داشبورد و صفحه سفارش‌ها

- افزودن محصول جدید به صورت مودال و ایجکسی در پنل مدیریت
- انتخاب تصویر شاخص محصول از رسانه وردپرس
- بازطراحی مدرن فروشگاه، تک‌صفحه محصول و سبد خرید
- فرآیند خرید مرحله‌ای: افزودن به سبد، ورود کاربر، مشاهده سفارش، پرداخت، نتیجه خرید
- اضافه شدن درگاه زرین‌پال در کنار زیبال
- انتخاب درگاه پیش‌فرض از تنظیمات افزونه
- ایجاد لایسنس دستی به صورت مودال در بخش لایسنس‌ها
- ویرایش لایسنس‌ها به صورت مودال

- وضعیت محصول به پیش‌نویس، فعال لایسنس‌دار و فعال بدون لایسنس تغییر کرد
- افزودن فیلد license_mode برای کنترل نیاز یا عدم نیاز محصول به لایسنس
- عدم صدور لایسنس برای محصولات فعال بدون لایسنس
- دانلود امن حساب کاربری و بروزرسانی برای محصولات بدون لایسنس بدون الزام license_key

== صفحات عمومی ==
[wplm_store]
[wplm_account]
[wplm_payment_result]

== REST API ==
POST /wp-json/wplm/v1/license/request
POST /wp-json/wplm/v1/license/activate
POST /wp-json/wplm/v1/license/check
POST /wp-json/wplm/v1/updates/check

== IPPanel Core Callback ==
POST /wp-json/wplm-ippanel/v1/receive-key

== لایسنس منیجر آمل نوین ==
فایل افزونه جداگانه لایسنس منیجر در مسیر زیر داخل بسته قرار دارد:
client/wplm-amolnovin-license-manager.zip
افزونه‌های ثانوی که از wplm-client-kit استفاده می‌کنند، در صورت نصب نبودن این افزونه، notice نصب/فعال‌سازی نمایش می‌دهند.

== بروزرسانی لایسنس منیجر آمل نوین ==
افزونه جداگانه لایسنس منیجر آمل نوین اکنون خودش بروزرسانی را از wp-plugin-market-manager بررسی می‌کند و آپدیت در بخش افزونه‌های وردپرس نمایش داده می‌شود.

== اصلاح بررسی بروزرسانی لایسنس منیجر ==
در نسخه 1.0.2 افزونه wplm-amolnovin-license-manager کش داخلی بررسی آپدیت هنگام force-check وردپرس نادیده گرفته می‌شود و درخواست آپدیت با پارامتر license_required=0 به سرور ارسال می‌شود.
